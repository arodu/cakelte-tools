# CakeLteTools plugin for CakePHP

Utilities for CakePHP **4.x** apps built on
[CakeLTE](https://github.com/arodu/cakelte): bulk actions, CSV export,
dependent selectors, steppers, enum helpers (`Color` + list traits),
FontAwesome icons, and small `Html`/`Text` helpers.

## Status

CakePHP 4.x only. Released as
[`v1.0.0`](https://github.com/arodu/cakelte-tools/releases/tag/v1.0.0).
Kept for legacy CakePHP 4 applications. For CakePHP 5 this functionality is
superseded by
[`arodu/cakephp-bootstrap-tools`](https://github.com/arodu/cakephp-bootstrap-tools)
and
[`arodu/cakephp-utility-kit`](https://github.com/arodu/cakephp-utility-kit).

## Requirements

- PHP >= 8.1
- `cakephp/cakephp` ^4.0
- `arodu/cakelte` ^1.2

## Installation

```
composer require arodu/cakelte-tools:^1.0
```
